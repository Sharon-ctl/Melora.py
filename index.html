Project guide

Discord Music Bot

A slash-command-only music bot on discord.py and lavalink.py, built to run unattended. The bot itself is the Python project in this folder. This page is a quick reference for setting it up and testing it.

Setup on Windows

  1. Create the environment: py -3.11 -m venv .venv
  2. Activate it: .venv\Scripts\Activate.ps1
  3. Install: pip install -r requirements-dev.txt
  4. Copy .env.example to .env and fill in the token, owner ID and Lavalink password.
  5. Set SYNC_ON_START=true for the first run only, then set it back to false.
  6. Start with run.bat.

Invite scopes: bot and applications.commands. Minimum permissions: View Channel, Connect, Speak, Send Messages (permissions integer 3148800). Send Messages is only used for notices outside a command and is skipped quietly if missing.
